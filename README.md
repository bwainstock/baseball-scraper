# Baseball Scraper

## Overview

This repository contains scripts for scraping baseball data from FanGraphs and generating structured tables for analysis.

## Repository Contents

- `scraper.py`: main scraping logic
- `baseball.py`: data processing utilities
- `teams.py`: team-related data handling
- `players.py`: player-related data handling
- `output/`: generated output files (if present)
- `data/`: scraped or intermediate datasets (if present)
- `test.json`: sample output data

## Usage

Use `scraper.py` to scrape baseball data from FanGraphs and generate structured table outputs.
